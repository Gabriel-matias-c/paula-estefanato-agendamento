# Paula Estefanato — Site e agendamento online

Protótipo de site de vendas e sistema de agendamento para uma manicure: o cliente escolhe serviço, data e horário, e o pedido segue para o WhatsApp. A profissional tem um painel para ver, confirmar e cancelar agendamentos e bloquear horários.

**Tecnologias:** HTML, CSS, JavaScript, Supabase (banco de dados e login)

## Estrutura

- `index.html`: página de vendas
- `agendamento.html`: fluxo de agendamento
- `admin/`: painel da profissional
- `sql/schema.sql`: tabelas do banco
- `js/supabase-config.js`: modelo de configuração (use suas próprias chaves; veja `SETUP.md`)
